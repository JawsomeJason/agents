# agents

Agent skills that run in any harness that reads the [Agent Skills spec](https://agentskills.io/specification).

| Plugin | What it does |
| --- | --- |
| `standards` | Mines a repo's review history into coding standards, each with its reason, and reviews diffs against them. |

Install steps for each harness are still to come. Conventions for contributors and agents live in [AGENTS.md](AGENTS.md).
